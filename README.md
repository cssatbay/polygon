# Квартирант

Сервис аренды жилья и подбора соседей в Алматы. Интерактивный прототип в планшетном формате (1194×834): экран вписывается в окно браузера.

## Экраны

| Страница | Что на ней |
|---|---|
| `index.html` | Вход по номеру телефона |
| `feed.html` | Лента объявлений, районы поиска, «Вам подходит» |
| `listing.html` | Объявление: фото, условия, почему подходит, хозяин |
| `map.html` | Карта: районы, обведённые пальцем |
| `quiz.html` | Анкета быта (16 вопросов) |
| `swipe.html` | Поиск соседа: карточка, совместимость, лайк |
| `match.html` | Взаимный лайк — коннект |
| `chats.html` | Коннекты и чат |
| `profile.html` | Профиль, верификация, анкета |

Экраны связаны ссылками, по ним можно пройти весь путь пользователя.

## Запуск

Открыть `index.html` в браузере. Для публикации на домене — GitHub Pages: Settings → Pages → Deploy from branch `main`, папка `/ (root)`.

## Структура

- `*.html`, `assets/` — статичный прототип
- `design/` — исходники макетов (варианты A–D) из дизайн-холста
- `tools/build-static.js` — сборка HTML из исходников: `node tools/build-static.js design .`
